# Ethan Smith Portfolio

A cinematic personal portfolio with a black Threads/Instagram-inspired palette, orange-and-teal film-grade accents, and sections for:

- Reel
- Awards
- Limer
- Blog posts and extracurricular field notes

Open `index.html` in a browser to view the site.

## Customizing

- Update contact and social links in `index.html` if they change.
- Put your reel at `assets/reel.mp4`; the hero player will automatically use it.
- Update award titles, blog cards, links, and Limer copy in `index.html`.
- Add real images later by replacing the `.note-image` gradient blocks with `<img>` tags.
